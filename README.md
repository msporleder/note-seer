# note-seer

listens for sounds, notates them on the staff, shows the note in scientific notation

Quiz mode shows two bars (scales, arpeggios, lines from Bach/Sor/jazz) and checks each note as you play it, with a live dot showing the pitch it hears

Transpose Mode allows you to show the staff transposed

The cents needle means it also works as a guitar tuner (set transpose to Guitar, tune the open strings E2 A2 D3 G3 B3 E4 until the needle centers)

It runs purely in the browser with javascript and does not record any audio, just shows the note it hears
